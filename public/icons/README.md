# Europe Explorer – Icons

This directory stores static icon assets used by Europe Explorer.

- Keep filenames lowercase and use hyphens, for example `historical-site.svg`.
- Prefer SVG for scalable interface and category icons; use PNG or WebP only when raster artwork is needed.
- Reference files from the app using paths such as `/icons/historical-site.svg`.
- Keep original editable/source files here as well when practical.
